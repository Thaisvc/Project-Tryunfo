# Tryunfo ♠️✨

Projeto de estudo desenvolvido durante a formação em **Desenvolvimento Web da Trybe**.  
Uma versão do clássico jogo de cartas *Super Trunfo*, construída com **HTML, CSS e JavaScript**, que permite criar cartas personalizadas, salvar no baralho e jogar interativamente.

---

## 💡 Sobre o projeto

O *Tryunfo* é uma aplicação web onde você pode:

✔️ Criar cartas com nome, atributos e imagem  
✔️ Salvar cartas em um baralho  
✔️ Sortear cartas aleatoriamente  
✔️ Comparar cartas e determinar vencedores  
✔️ Ver automaticamente o resultado da rodada  

Esse projeto consolida:

- Manipulação da DOM  
- Eventos de formulário e botões  
- Lógica de jogo com comparações  
- Validações de entrada  
- Estrutura e estilos front-end

---

## 🛠 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (DOM e eventos)

---

## 🚀 Como usar

### 1. Clone o repositório

```bash
git clone https://github.com/Thaisvc/Project-Tryunfo.git
cd Project-Tryunfo
````

### 2. Abra no navegador

Basta abrir o arquivo:

```
index.html
```

ou rodar com um servidor leve:

```bash
npx serve .
```

ou

```bash
npm install -g http-server
http-server
```

## 🎮 Funcionalidades

### 🔹 Criar cartas

* Insira nome, atributos e imagem
* Marque se é a carta *Tryunfo*
* Salve no baralho clicando em “Salvar”

---

### 🔹 Ver cartas

* As cartas são exibidas na tela
* Cada carta mostra seus atributos

---

### 🔹 Sortear cartas

Ao clicar no botão de sorteio:

✔️ Uma carta é escolhida para você <br>
✔️ Outra é escolhida para o oponente <br>
✔️ Os atributos são comparados <br>
✔️ Resultado é exibido automaticamente <br>
